~~~ini
description=`metadata T about x;` is typed by `T` and declares no name (MetadataUsageDeclaration); a body-less `#Tag` prefix in a package or part usage body annotates the member that follows it (PrefixMetadataMember), including when that member has its own body; metadata annotations are OwningMemberships, so port and metadata-body rules over owned usages and features do not see them
type=file
libraries=standard
require_no_diagnostics=true
require_complete_publication=true
~~~

~~~sysml
}
~~~
