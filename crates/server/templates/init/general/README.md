# My SysML v2 Project

This starter workspace is ready to validate with Spec42.

## Project structure

```
model/
  definitions/        System and part definitions
  configurations/     System configurations
  requirements/       Requirements specifications
  library/            Domain-specific type libraries
```

## Quick start

```bash
spec42 check model --workspace-root .
```

Open the directory in a SysML v2-capable editor to browse and extend the model.
