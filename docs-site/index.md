# Build your first SysML model

Install Spec42, open an example, and explore your model with the editor and command-line tools.
Choose the documentation version that matches your installation. Run `spec42 --version`
to check your CLI version, or check the installed extension version in VS Code.

## Get started

1. [Install Spec42 and open your first model](getting-started.html).
2. [Explore the examples](examples.html) for complete models you can adapt.
3. [Check the supported features and limitations](features.html) for this version.

## Work with your model

- [Diagram views](diagrams.html): open authored views and inspect their graphical output.
- [Feature Inspector](inspector.html): explore resolved elements, relationships and values.
- [Projects and libraries](libraries.html): organize sources and use bundled or additional libraries.
- [Validation](validation.html): check your model and understand diagnostics.

## Put checks into your workflow

[Validate models in GitHub Actions](github-action.html), or
[connect an AI assistant](assistants.html) to the same analysis tools.

If something goes wrong, start with [troubleshooting](troubleshooting.html).
See [what's included](included.html) for the libraries bundled with your release.
