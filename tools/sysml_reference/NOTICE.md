# Third-party reference-material notice

The two `.kebnf` files in this directory are derived from the OMG KerML and
SysML v2 textual specifications. They are included solely as small reference
inputs for grammar lookup. Their original header attribution has been preserved.

No OMG XMI, JSON schema, standard-library model, PDF, or interchange fixture
is included in this repository by this migration. Users who need metamodel
queries or conformance comparison must provide an authoritative local input
through `--schema` and comply with that input's applicable terms.
